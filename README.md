# Aina Harmony landing page

This is an independent, static landing page for a separate Hostinger subdomain.

## Deploy to Hostinger

1. In Hostinger, create or select the intended subdomain.
2. Open its document root in File Manager (usually `public_html/<subdomain>`).
3. Upload `index.html` from this folder.
4. Visit the subdomain and submit a test lead form after its form endpoint is connected.

All logo, favicon, and villa imagery use absolute CMR/WordPress URLs, so no image files need to be uploaded with this page.

## Important

The form currently shows a confirmation message and sends GTM events, but it does not yet send lead data to an API, email inbox, or CRM.
